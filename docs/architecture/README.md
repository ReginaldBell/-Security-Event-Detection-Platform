- [System Overview](securewatch-system-overview.svg)

These are designed as focused architecture boards instead of one compressed mega-diagram. Use them directly in docs, import them into Figma, or export them as PNG/PDF for presentations and portfolio material.

## Figma Export Notes

When editing in Figma:

1. Put each board inside a 2560 x 1440 frame.
2. Enable **Clip content** on the selected frame.
3. Export the frame, not the individual objects.
4. Use PNG 2x for presentations, SVG for docs, or PDF for portfolio/capstone packages.
